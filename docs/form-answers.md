## Steps to produce each link

1. **GitHub repo** — the `recalldesk/` project is committed locally; push it to GitHub
   (repo created via `gh`, or manually). Paste the repo URL.
2. **LinkedIn post** — publish the text from `docs/linkedin-post.md`, add the article URL
   as the first comment, add the repo link in the main post, then comment with
   https://github.com/vectorize-io/hindsight . Paste the post URL.
3. **Article** — publish `article.md` to Medium / Dev.to / Hashnode / Substack / LinkedIn
   Article (public + linkable). Fix header/link formatting for the platform. Paste the URL.
4. **Video** — record per `docs/demo-script.md` (OBS/Loom, 1080p, 2-5 min), upload PUBLIC
   to YouTube with a 16:9 thumbnail (Nano Banana / Gemini). Paste the URL.
5. **Reddit** — submit the article URL as a Link post on one of: r/llmdevs, r/sideproject,
   r/aiagents, r/aimemory. Paste the post URL.
