Customers shouldn't have to repeat their story. Most support agents make them.

I built a support copilot that never forgets.

What changed:
- Every conversation is retained with real timestamps, then recalled four ways at once: semantic, keyword, graph, temporal
- "It broke AGAIN" finds last month's ticket instantly — with its resolution status
- Repeated facts consolidate into observations with source counts, so the agent's beliefs stay grounded
- A separate cross-customer playbook bank means the agent learns which fixes worked for other customers
- Memory off: generic small talk. Memory on: "Hi Priya — #4837 was the PDF bug on v2.4.0; the fix shipped in v2.4.1."

The memory layer is Hindsight. That choice did most of the heavy lifting.
